OptionWhales provides AI-powered options flow intelligence, detecting unusual institutional activity, tracking gamma exposure, and offering real‑time market‑research tools for traders and AI agents. The platform offers free and Pro plans, API access via REST and WebSocket, and integrates with AI assistants for automated analysis.

**Areas:** AI · Options · Trading · MarketResearch · API
